<a id="checkpoint"></a>
## 🌙 セーブポイント：どんな人？

**マキシム（Maxime）**です。コンピューターや新しい発見、そして「**これ、作ってみたら面白そう！**」という小さなひらめきが大好きです。😄

**42 Paris**では、C言語の基礎から始まり、アルゴリズム、システム、ネットワーク、Web開発など、少しずつ挑戦の幅を広げてきました。**2026年2月26日**にCommon Coreを修了しましたが、気分としては **「次のステージが解放された！」** という感じです。🎉

仕組みを理解したり、面倒な作業をもっと簡単にしたり、実際に試しながら学んだりすることが好きです。ときにはコードを壊してしまっても、直すところまで含めて冒険だと思っています。

<a id="offline"></a>
## ⛩️ ターミナルを閉じたら…

私の世界は `git push` だけではありません！ **日本**の街並みや雰囲気、まだ知らない場所に強くひかれています。それから **ゲーム、ポケモン、ギーク文化、小さな隠しネタ**も大好きです。🎮⚡

旅行をして、新しい景色を見て、たくさんのアイデアを持ち帰るのも楽しみです。これまでに**日本**や**フィリピン**、ヨーロッパのさまざまな場所を訪れました。旅から得られる刺激は、新しいプログラミング言語を学ぶときに負けないくらい大きいと思います。🌍

**つまり：** コードと好奇心、少しのゲーム愛、そしてこれから始まるたくさんの冒険です。
